Stated preconditions: Application is deployed; health check endpoints are available; previous deployment version and rollback procedures are prepared.

Verification boundary: Those deployment preconditions were supplied as the intended scenario, not independently verified. No deployed URL, actual current/previous SHA, image digests, or deployment evidence bundle was supplied. No live rollback, Jenkins job, deployment, AWS request, or Parameter Store write was performed.

Execution date: 2026-10-29, Asia/Ho_Chi_Minh (UTC+07:00). **15 Pass (local component/fixture checks), 5 Not executed (live deployment/evidence checks)**. DHR-TC01–03 mount the existing `apps.backend.api.health` router at `/api` in an isolated FastAPI TestClient; full application startup is excluded and the model HTTP dependency is mocked. DHR-TC04–15 execute the repository's actual smoke/deploy/rollback shell scripts with fake `curl` and `aws` executables. Responses, previous revisions, image digests, and SSM outcomes are controlled fixtures, not real deployment evidence. HTTP retries, TLS, remote command execution, image recovery, and persistence of AWS writes are not established by these Pass results.

Files under test: `apps/backend/api/health.py`, `jenkins/smoke-and-rollback.sh`, `jenkins/deploy-with-rollback.sh`, `jenkins/deploy-staging.sh`, and `jenkins/ssm-command.sh`. No application or pipeline code was changed.
