## Quỹ đạo camera bằng GLB riêng (`scene.camera_path_url`)

Chốt với user: KHÔNG bake camera vào model 106 MB. Xuất một GLB **chỉ có camera +
animation clip** (vài chục KB), app nạp như asset thứ hai và seek theo audio.

Backend:
- `scene.camera_path_url TEXT` — thêm vào `apps/backend/models/scene.py` và bản
  mirror `apps/backend/common/models/scene.py`, `schema.sql`.
- Migration idempotent: `apps/backend/migrations/2026-10-26_scene_camera_path_url.sql`
  (`ADD COLUMN IF NOT EXISTS`). Đã áp vào DB local bằng psycopg (không có psql trên PATH).
- `CameraOut.path_url` + `_resolve_urls(camera_out, policy, "path_url")` trong
  `api/heritage.py`. Lưu ý: `R2_PUBLIC_BASE_URL` không set trong .env nên URL
  tương đối đi nguyên xi — phải dùng URL tuyệt đối như `model_asset.file_url`.

Frontend:
- `features/tour/three/camera-path.ts` (mới): `createCameraPath(gltf, url, modelRoot)`.
  `sample(seconds)` = `action.time = t; mixer.update(0)` → clip được ĐÁNH GIÁ tại t,
  không tích luỹ ⇒ seek/pause/tua đều đúng. KHÔNG set `action.paused` (paused làm
  `_updateTimeScale` trả 0 và seek mất tác dụng).
  Điểm ngắm: node `CAM_Target` → tia chiếu vào model (cache khoảng cách) → tâm hộp bao.
  `pickCameraClip` (tên khớp /cam|path|fly|orbit|dolly/ → clip dài nhất),
  `pickCameraNode` (camera mà clip điều khiển → camera phối cảnh đầu → node tên /cam/).
- `tour-engine`: `cameraPath` là "nguồn ghi" thứ tư, tiến theo `playbackClock` trong
  vòng lặp render (`updateCameraPath`), NHƯỜNG khi `isFlying()`. API: `setCameraPath(url)`
  (async, có token chống nạp muộn của cảnh cũ), `applyCameraPathStart`, `resumeCameraPath`
  (bám `playbackClock` khi thoát Explore), `stopCameraPath`, `hasCameraPath`,
  `getCameraPathDuration`. `applyCameraPreset`/`flyCameraPreset`/`applyGLBCamera` đều
  `releaseCameraPath()` — một nguồn ghi duy nhất.
- `camera-controller`: thêm `applyPathPose(pos, target, fov)` = `applyPose(..., upY)`.
- `useTourPlayer`: ưu tiên `path_url` → preset DB → camera nướng → `fit()`; effect audio
  `if (engine.hasCameraPath()) return;` để timeline preset không giành camera.

Bẫy đã gặp và fix: `cameraController.fit()` chạy khi model nạp xong, ghi đè pose path
vừa áp, mà `updateCameraPath` lại bỏ qua vì `playbackClock` không đổi ⇒ camera kẹt ở
góc fit. Fix: `cameraPathTime = Number.NaN` ngay sau `fit()`.

Verify: `tests/camera-path.test.ts` 7/7 pass (seek đúng, không tích luỹ, kẹp 2 đầu,
target theo hướng nhìn). Browser thật (Playwright chặn response API để tiêm `path_url`,
file mẫu `public/tour-assets/camera-paths/sample-camera-path.gltf`): tua +15 s → camera
