
## ĐÚNG RA: "Explore in 3D" (walk) dùng DẤU CHÂN, "Dive Deeper" mới dùng lens

User đúng — mình đọc thiếu CSS. Trong `styles.module.css`:
```css
.exploreCorner.free-explore .exploreCorner-iconWrap { visibility: hidden; }  /* ẩn lens */
.exploreCorner.free-explore .exploreCorner-footsteps { display: block; }     /* hiện dải dấu chân */
```
⇒ Nút góc desktop ở chế độ `free_explore` (walk, nhãn "Explore in 3D") **ẩn icon lens** và thay bằng `.footstepStrip` — 8 dấu chân `icon_footstep_l/r.svg` chạy dọc, animation `footstepAppear` 6s, delay mỗi 0,75s, trong khung tròn `rotate(45deg)`.

**Sửa `HeritageViewer.tsx`:** trong `#diveDeeperInline`, nếu `player.initialExploreMode === "walk"` render `<span class="diveDeeperFootsteps">` với 3 ảnh dấu chân (l/r xen kẽ), ngược lại mới render `explore_lens.svg`.

**CSS:** `.diveDeeperFootsteps` 16×36 overflow hidden; `.footstepMini` 7×16, `animation: footstepAppear 2.7s linear infinite`, delay -0.9/-1.8/0 (nhịp = duration/số dấu chân, đúng công thức desktop 6s/8 = 0,75s); top 0/10/20. Đổi `.diveDeeperInline img` → `.diveDeeperInline > img` để không ép kích thước lên ảnh dấu chân.

**Bài học:** trước khi kết luận "asset giống nhau", phải đọc hết CSS modifier của element đó (`.free-explore`).
